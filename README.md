# Sign Language Recognition System

A collaborative Streamlit project for real-time sign language recognition using a trained machine learning model.

## Technologies Used

- Python
- Streamlit
- Machine Learning

## Project Files

- `app.py` — Streamlit application
- `asl_model.pkl` — Trained machine learning model
- `requirements.txt` — Python dependencies

## Project Type

Collaborative academic project.

## Contributors

- Sri Meher Satwik

## Purpose

This project demonstrates the use of machine learning and Streamlit to build a sign language recognition application.
